### Обо мне

DevOps-инженер и разработчик: автоматизирую инфраструктуру, пишу сервисы на **Python/Go**, применяю **ML** там, где это даёт пользу в проде.  
Сейчас в магистратуре ТвГУ — делаю ВКР по прогнозированию аномалий в мониторинге. До этого защитил бакалаврский диплом по банковскому скорингу.

**Что умею на практике:** IaC (Terraform, Ansible), контейнеры и оркестрация, мониторинг (Zabbix / Prometheus / Grafana), микросервисы, CI/CD, классический ML и чуть железа на ESP32.
